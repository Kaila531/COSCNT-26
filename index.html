To add a screenshot of my chosen webiste to my personal webiste I took the folowing steps:

  • 1. Press the "prt sc" button on my keyboard to take a screenshot that auto saves to a photo file.
  • 2. On VScode or Glueops, I added a new file called "images" under my project folder.
  • 3. Drag and drop my chosen picture from the file explorer on my computer straight to the images file I created on glueops.
  • 4. Last I right clicked the image to copy the path and pasted it in the code in a new paragraph.
